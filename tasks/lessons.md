# Lessons

## 日本語コピー/組版
- **和文フォント未指定が「翻訳感」の最大要因**：欧文フォント（Inter等）のみだと日本語はOSフォールバック表示になり、字面・ウェイトが揃わず安っぽく見える。日本語ページには必ず Noto Sans JP 等の和文フォントをスタックに含め、見出しに `font-feature-settings: "palt"`、本文に広めの `line-height` を当てる。
- **JSONに `<br>` を埋め込まない**：特定画面幅前提の改行は他幅で崩れる。BudouX + `max-width` + `text-wrap: balance/pretty` で制御する。
- **読点前後の折り返し禁止（ワードジョイナー挿入）は逆効果**：日本語では読点直後はむしろ自然な改行位置。`line-break: strict` の禁則処理で十分。不可視文字はコピペやBudouX解析に混入する副作用もある。
- **表現の重複と比喩の渋滞を避ける**：「一気通貫」「伴走」等の強い語は多用すると翻訳ツール感が出る。サイト全体で使用回数を管理する。
- **英数字と日本語の境界スペースはルールを1つに統一**（このサイトは「入れない」で統一）。
- **金額・単位などローカライズ判断はユーザーに確認**：ドル/円建ては商流依存。勝手に換算せず確認する（今回はドル建て維持の判断）。
- **`word-break: keep-all` 下では `<wbr>`/ZWSP の改行機会が Chromium で抑制される**：仕様上は効くはずだが実ブラウザで折り返さない。確実に改行位置を制御したい見出し等では、レスポンシブに効かせた強制改行 `<br class="sm:hidden">`（モバイルのみ表示、`sm`以上は`display:none`）を使う方が堅実。
- **コピーの文字数はレイアウトに影響する**：見出しを1文字伸ばすだけで狭幅で見切れることがある。コピー変更後はモバイル幅で必ず実描画確認する。
- **多言語サイトは言語ごとに折り返し要件が異なる**：日本語向けの強制改行を英語ページにそのまま入れると語が不自然に分かれる。ページが別ファイルなら言語別に最適化する。
